# Music Assets for Yogi's Little Universe ❤️

Place your romantic mp3 song here named:
`romantic.mp3`

(File path: `public/assets/music/romantic.mp3`)

Note: If no audio file is placed here, the website automatically plays a soothing, emotional romantic piano & ambient chords soundtrack synthesized on-the-fly using the Web Audio API, so music will always work out of the box!
